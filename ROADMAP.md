# PolyMerge Implementation Roadmap

- **Sprint 1 (Weeks 1-2): Infrastructure.** Scaffold Fastify API, deploy Neo4j, and set up basic dummy-data combinatorial search.
- **Sprint 2 (Weeks 3-4): Baselines.** Generate TransE graph embeddings and connect the first GCN layer to the Fastify API.
- **Sprint 3 (Weeks 5-6): ML Refinement.** Integrate RDKit molecular features and optimize inference response times.
- **Sprint 4 (Weeks 7-8): Polish.** Connect the interactive frontend, implement GNNExplainer for safety reasoning, and validate against known clinical trials (e.g., Polycap).
